# Phase 0 — Foundation & Environment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the foundational infrastructure (env vars, Convex, Clerk, locale routing, admin route grouping) so every later phase in `PLAN.md` has something real to build on top of.

**Architecture:** Next.js App Router with a `[locale]` segment wrapping all translated public content; global file-convention routes (`robots.ts`, `sitemap.ts`, favicon/icons/manifest) stay at the top-level `app/` directory since they're independent of the layout tree. Locale detection/redirect and (later, Phase 2) auth both run through the single `proxy.ts` file — Next.js 16 renamed `middleware.ts` to `proxy.ts` (same functionality, new file name). Convex and Clerk are wired up as providers with no schema/route-protection logic yet — that's Phase 1/Phase 2.

**Tech Stack:** Next.js 16.3.0 (App Router), React 19, TypeScript (strict), `next-intl` 4.13.5, Convex, `@clerk/nextjs`, Tailwind CSS 4.

## Global Constraints

- TypeScript `strict: true` is already enabled in `tsconfig.json` — every new file must type-check with no `any`.
- This Next.js version renamed `middleware.ts` → `proxy.ts` (file convention only, same `NextRequest`/`NextResponse` API). Only one `proxy.ts` is allowed per project — Phase 2's Clerk route protection will need to be added into the *same* file created in Task 4, not a second file.
- Locales are `en`, `ar`, `tr` with `en` as default, per `TECH_STACK.md`.
- Global files (`favicon.ico`, `icon0.svg`, `icon1.png`, `apple-icon.png`, `manifest.json`, `globals.css`) must stay at the top-level `app/` directory, not inside `app/[locale]/`.
- No secrets committed to git — real values go in `.env.local` (already gitignored by `create-next-app`'s default `.gitignore`), only placeholder names go in `.env.example`.
- Don't touch anything beyond Phase 0 scope (no Convex schema, no Clerk route protection, no admin CRUD) — those are separate phases/plans.
- **No agent runs `git add` or `git commit` — ever, for any task.** All changes stay uncommitted in the working tree. The human reviews and commits everything at the end, in whatever grouping they choose. (Every "Commit" step below is replaced by a "Do not commit" note for this reason.)

### Task 4: `proxy.ts` for locale detection/redirect

**Files:**
- Create: `proxy.ts`

**Interfaces:**
- Consumes: `routing` from `i18n/routing.ts` (Task 3).
- Produces: locale-prefixed redirects for every request except static/metadata files. Phase 2 will edit this same file to add Clerk auth — it must stay the *only* proxy file in the project.

- [ ] **Step 1: Create `proxy.ts`**

```ts
import createMiddleware from "next-intl/middleware";
import { routing } from "./i18n/routing";

export default createMiddleware(routing);

export const config = {
  matcher: [
    "/((?!api|admin|_next/static|_next/image|favicon.ico|icon0.svg|icon1.png|apple-icon.png|manifest.json|robots.txt|sitemap.xml|.*\\..*).*)",
  ],
};
```

> **Fixed during Task 7 execution:** the matcher above originally omitted `admin`, which meant `/admin` got caught by the locale middleware and redirected to `/en/admin` (404) — contradicting Task 7's whole purpose (`/admin` staying outside `[locale]`, unprefixed). Caught by Task 7's implementer, root-caused and fixed by the controller in this file. If later phases add more portal path prefixes outside `[locale]` (e.g. Agent/Client portals per the roles/portals spec), add them to this same negative-lookahead list too.

Expected: `HTTP/1.1 307 Temporary Redirect` with a `location` header pointing to `/en`.

Run: `curl -I http://localhost:3000/favicon.ico`

```tsx
import { cn } from "@/lib/utils";
import { routing } from "@/i18n/routing";
import { ConvexClientProvider } from "@/components/providers/convex-client-provider";

const inter = Inter({ subsets: ["latin"], variable: "--font-sans" });

const poppins = Poppins({
  subsets: ["latin"],
  weight: ["400", "500", "600", "700"],
  variable: "--font-heading",
});

const geistMono = Geist_Mono({
  variable: "--font-geist-mono",
  subsets: ["latin"],
});

export const metadata: Metadata = {
  title: "QuickTalk Real Estate | Dubai Properties",
  description:
    "Explore properties for sale and rent, off-plan developments, and real estate investment opportunities in Dubai.",
  appleWebApp: {
    title: "QTRE",
  },
};

export function generateStaticParams() {
  return routing.locales.map((locale) => ({ locale }));
}

export default async function RootLayout({
  children,
  params,
}: LayoutProps<"/[locale]">) {
  const { locale } = await params;

  if (!routing.locales.includes(locale as (typeof routing.locales)[number])) {
    notFound();
  }

  return (
    <html
      lang={locale}
      dir={locale === "ar" ? "rtl" : "ltr"}
      className={cn("h-full", "antialiased", inter.variable, poppins.variable, geistMono.variable, "font-sans")}
    >
      <body className="min-h-full flex flex-col">
        <NextIntlClientProvider>
          <ClerkProvider>
            <ConvexClientProvider>{children}</ConvexClientProvider>
          </ClerkProvider>
        </NextIntlClientProvider>
      </body>
    </html>
  );
}
```
